ARCHEOS: Plataforma Integral de Arqueometría: Inventario y Análisis Multimodal de Materiales Arqueológicos

Actualización del Proyecto: Lanzamiento y Avances de Archeos

Archeos es una plataforma integral web diseñada para el inventario, gestión y análisis multimodal del patrimonio arqueológico, con un enfoque particular en el Noroeste Argentino (NOA). Su gran diferencial es la capacidad de estructurar datos complejos (espaciales, morfométricos y tafonómicos) para alimentar modelos estadísticos y de Inteligencia Artificial (Machine Learning), permitiendo automatizar y profundizar la clasificación de materiales, especialmente del material cerámico.

Informe Detallado de Logros y Funcionalidades

  • Arquitectura de Seguridad y Roles: Implementación de un sistema de autenticación robusta con contraseñas encriptadas y tokens criptográficos (JWT). Todas las rutas de modificación en el servidor (FastAPI) están blindadas. El sistema garantiza la trazabilidad científica capturando la autoría de cada registro. En el Frontend (React), la interfaz se adapta al usuario, protegiendo los datos de borrados accidentales si el operador tiene un rol de estudiante y no de administrador.
  • Gestión de Jerarquía Espacial: Sistema completo para estructurar la procedencia del material en cascada (Sitios > Sectores > Cuadrículas > Capas Estratigráficas).
  • Módulos de Inventario Especializado (CRUD Completo): Registro detallado para Cerámica (manufactura, morfología, tafonomía), Lítico (análisis dinámicos según la clase de artefacto), Óseo (identificación taxonómica, MNI, marcas antrópicas) y Suelo/Carbón. Todos los módulos cuentan con auto-llenado y borrado en cascada.
  • Exportación y Análisis Estadístico: Capacidad de ingreso masivo vía CSV y exportación estandarizada para R, Pandas o Excel. Los endpoints en Python calculan estadísticas complejas al vuelo.
  • Inteligencia Artificial y Visión Computacional: Sistema para subir y asociar fotografías de perfiles e iconografía. Contamos con un Motor de Predicción (Random Forest) funcional que procesa datos morfométricos, entrena un modelo para estimar el "Tipo Cerámico" y devuelve métricas de precisión y la importancia de cada variable.

Trabajos a Futuro y Tareas Pendientes

A Corto Plazo (Agenda Inmediata):

Implementaremos el "Modo Edición" en masa para el material lítico (Débitage) y actualizaremos el motor estadístico en Python para que agrupe cantidades y pesos de las bolsas, superando el simple conteo individual de piezas.

A Mediano y Largo Plazo:

Definiremos la arquitectura estratégica para abrir la plataforma a otros institutos (optando entre un Modelo de Red Colaborativa o Software como Servicio multi-tenant). Además, construiremos visualizaciones de datos (Dashboards) interactivos en React y expandiremos el motor de Machine Learning con algoritmos complementarios (como Support Vector Machines - SVM) para optimizar continuamente la clasificación del patrimonio.
